# Pausen-Profi – Ideen finden, mitmachen & einen Plan B haben

Browser-Lernspiel für die Grundschule (Klasse 1–4) aus der Reihe **Förderfreude Games**.
Kernbotschaft: **„Mein erster Plan klappt nicht? Dann kann ich einen Plan B finden."**

## Starten
`index.html` im Browser öffnen. Das Spiel besteht aus **einer einzigen Datei** und läuft ohne Internet.
Für GitHub Pages oder Netlify die Datei unverändert hochladen. Mit `index.html#testansicht` lassen sich alle Szenen zur Prüfung ansehen.

## Die vier Bereiche
| Bereich | Frage | Umfang |
|---|---|---|
| Schulhof entdecken | Was könntest du hier machen? | 15 Ideen-Orte, je 4 Ideen |
| Pausen-Mixer | Misch dir eine Idee! | 100 Pausenideen, 3 Fragen, 3 Vorschläge |
| Plan B | Wenn dein erster Plan nicht klappt. | 28 Situationen, 6 pro Runde |
| Mitmachen & Loslegen | Allein, zu zweit oder gemeinsam. | 22 Situationen, 6 pro Runde |

Keine Punkte, keine Zeit, kein „Richtig/Falsch". Ein Nein ist manchmal okay, Alleinsein ist okay, eine Pause darf ruhig sein.
Die vier Zeichen **SPÜR – SCHAU – PROBIER – PLAN B** begleiten das Spiel (keine feste Reihenfolge).
Bei wiederholtem Ausschluss weist das Spiel kurz und ruhig auf Unterstützung hin.

## Technik
- Reines HTML/CSS/JavaScript, 24 Kinderfiguren und der Schulhof als Inline-SVG
- Keine Frameworks, externen Schriften, Bilder, APIs, Cookies, Tracking oder LocalStorage
- Responsiv von 320 bis 2560 px; Touch, Maus und Tastatur; sichtbare Fokusrahmen; `prefers-reduced-motion`
- Vorlesen (de-DE) nur auf Knopfdruck; ohne Stimme bleibt das Spiel voll spielbar
- „Meine Pausenideen“ (bis zu 5 Favoriten) gelten nur für die laufende Sitzung
